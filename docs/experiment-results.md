# IEN experiment results (generated)

This file is generated by `simulation/experiments.py`; do not edit it by hand. Risk source: **Random forest**. Seed 20261016; Python 3.11.9, numpy 2.4.6, pandas 3.0.6, scipy 1.17.1, simpy 4.1.2. The settings come from `docs/decisions.json`.

**How to read it**

- Risks and show-ups come from real out-of-sample predictions and the real outcomes of the 27 days the model did not see. Session settings: 16 slots x 15 min, mean consultation 7.5 min (range 5–10 min, variability 0.5), lateness deviation 4 min, 20 booking requests. The consultation time (5–10 min) comes from state hospital outpatient practice; slot length, lateness and demand are **assumptions** (`docs/decision-list.md`).
- All comparisons are **paired**: every policy sees the same random sessions (common random numbers). Differences are given against the base policy; brackets hold the 95% confidence interval, and `d` is the paired effect size (Cohen's d_z).
- Times are minutes per session; "Seen" is the number of patients per session.
