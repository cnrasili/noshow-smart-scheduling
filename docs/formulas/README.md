# Formüller

Projede kullanılan hesaplama formülleri. Her formül için ayrı bir bölüm açın:

```
## Formül adı
- Formül: $...$
- Değişkenler: ...
- Kaynak: Forecast dersi, hafta X
- Kod: `path/to/file.py`
```

Dosyalar: `forecast.md` (tahmin formülleri), `overbooking.md` (overbooking hesapları), `rules.md` (hasta, bölüm ve yaş gruplarına göre gelme olasılığı kuralları).
