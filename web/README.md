# Web Application

Appointment booking web application with patient and doctor interfaces.

## Scope

- Database design: patients, doctors, slots, appointments
- Calendar/slot algorithm: slot generation from doctor working hours, conflict checks, more than one patient per slot for overbooking
- Patient interface: sign in, view available slots, book and cancel appointments
- Doctor interface: daily calendar, appointment list, mark attended / no-show
- Calls the overbooking service at booking time (see [API contract](../docs/api-contract.md))
